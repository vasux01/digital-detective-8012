### Task 4.2 — Compare compiler and interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates source code before execution | Executes instructions at runtime |
| Typical output | Often produces machine code or another translated form | Usually executes instructions directly |
| One example | GCC for C | Python interpreter |
| One advantage | Can produce efficient executable programs | Convenient for testing and debugging |

**Explanation:**

A compiler translates the source code before the program runs. An interpreter reads and executes instructions at runtime. A compiler often produces a separate output, while an interpreter generally executes the program directly. Both approaches help computers execute programs.
