## 1. Task / objective

Explain how a computer receives input, processes information, produces output and stores results. Identify hardware, software and everyday computer-based systems.

## 2. Work completed

### Task 1.1 — IPOS example: typing and saving a document

| Stage | What happens | Hardware / component |
|---|---|---|
| Input | I press keys to enter text and use the trackpad to select commands. | Keyboard and trackpad |
| Processing | The application interprets the keystrokes and updates the document in memory. | CPU and RAM |
| Output | The document appears on the display. | Screen / display |
| Storage | I save the document so it can be opened later. | SSD, hard drive or cloud storage |

The activity starts with keystrokes, is handled by the application and processor, appears on the screen, and is saved to storage when I use the save command.

## 4. My understanding

IPOS describes a common flow in a computer system: information is entered, processed, presented and saved. Hardware is the physical equipment. Software is the set of instructions and applications that make the hardware useful. Operating-system software manages the computer, application software helps users complete tasks, and utility software supports maintenance or protection.
