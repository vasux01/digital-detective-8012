## 4. My understanding

A Git repository is a workspace that stores project files and tracks changes made to them over time.

The assignment folders are organised by mission so that every activity has its own documentation and can be reviewed independently. This also makes it easier to track progress and maintain a clear project structure.

## 5. Difficulties faced

macOS automatically created a `.DS_Store` file inside the project folder.

## 6. How I resolved them

Added `.DS_Store` to the `.gitignore` file so that this macOS-generated file is excluded from Git tracking.
