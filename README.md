# The Digital Detective

A practical mini system report for the **Diwali Independent Learning Assignment**.

This repository documents a sequence of nine missions exploring computer fundamentals, Terminal operations, operating systems, program execution, number systems, Git/GitHub and computer networking.

> **Before publishing:** Rename this repository and its local folder to `digital-detective-XXXX`, replacing `XXXX` with the last four digits of your USN as required by the assignment. Do not put your full USN, email, computer username, device name, IP address, Wi-Fi name, passwords or access tokens in this public repository.

## Topics explored

- Input, processing, output and storage (IPOS)
- Hardware, operating-system software, application software and utility software
- Command-line navigation and safe file management
- Command options, pipes and package managers
- Operating-system responsibilities, processes, paths, storage and permissions
- Compilers, interpreters and Python execution
- Decimal, binary and hexadecimal number systems
- ASCII, UTF-8 and character encoding
- Git commits, branches, remote repositories and Pull Requests
- LAN, MAN, WAN, DNS, routers, protocols, packet switching and client-server communication

## Run the number converter

Python 3 is required. From the repository root, run:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter a positive whole number when prompted. The program displays its binary and hexadecimal forms.

## Learning summary

The assignment connects basic computer concepts with practical activities. It shows how information moves through a computer, how an operating system manages resources, how programs are executed, how data can be represented in different bases, and how developers track and share work using Git and GitHub.

## Mission workflow

Each mission is intended to be completed, documented, reviewed, committed and pushed separately before the next mission begins. The commit and GitHub activity recorded in each mission README must reflect what was actually done.
